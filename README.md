# Swiggy SQL Case Study

## Project Overview

This project analyzes Swiggy's relational database using SQL. The analysis focuses on customer activity, restaurant performance, revenue generation, order trends and delivery-partner performance.

## Project Objectives

- Analyze customer ordering behaviour
- Measure restaurant ratings and revenue
- Identify active and inactive customers
- Examine recent order activity
- Evaluate delivery-partner performance
- Discover customer and restaurant ordering patterns

## Tools and Techniques

- MySQL
- SQL Joins
- LEFT JOIN and Self Join
- Subqueries
- EXISTS and NOT EXISTS
- GROUP BY and HAVING
- Aggregate functions: COUNT, SUM and AVG
- Date functions

## Key Analysis Performed

1. Identified customers living in Delhi
2. Calculated the average restaurant rating in Mumbai
3. Identified customers who placed at least one order
4. Calculated order frequency by customer
5. Measured revenue generated by each restaurant
6. Identified the five highest-rated restaurants
7. Identified customers who never placed an order
8. Analyzed Mumbai customer orders
9. Examined orders from the latest 30-day period
10. Evaluated completed deliveries by delivery partner
11. Identified customers ordering on exactly three different days
12. Found the delivery partner serving the most unique customers
13. Compared same-city customers ordering from the same restaurants

## Key Insights

- Mumbai restaurants recorded an average rating of 4.30.
- Active and inactive customers require different engagement strategies.
- Restaurant revenue analysis identifies strong and underperforming partners.
- Order-frequency analysis supports customer segmentation.
- Delivery analysis highlights active and experienced delivery partners.
- Location-based ordering patterns can support targeted promotions.

## Business Recommendations

- Provide personalized offers to frequent customers.
- Use first-order discounts to activate inactive customers.
- Promote highly rated and high-revenue restaurants.
- Support low-performing restaurants through targeted campaigns.
- Recognize consistently active delivery partners.
- Run city-specific restaurant promotions.
